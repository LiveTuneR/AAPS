No database schema/index migration is added: R1's actual schema/DAO SQL fixture already supplies the query-plan evidence. Remaining profile-at-time reads in Wear/TDD cannot be replaced with one current profile without changing semantics. Release routine logs for graph IOB arrays and REST page payloads now use lazy counts; SMB decisions, commands, delivery/reconciliation, stale generations and loss markers remain visible.

Counters are process-local and bounded; only support export sorts latency windows and serializes aggregate data. CPU time comes from device process accounting/Perfetto. Coroutine wall time is not presented as thread CPU time.
